# Elementor

Build and edit WordPress pages with the Elementor visual editor.

This repository contains a copy of the plugin distribution by Elementor.com. [Upstream plugin page](https://wordpress.org/plugins/elementor/)

## Requirements

WordPress 6.8+, PHP 7.4+

## Installation and use

1. Place the plugin files in `wp-content/plugins/elementor/`.
2. Activate **Elementor** from **Plugins** in the WordPress dashboard.
3. Open a page and select **Edit with Elementor**.

See the [distribution README](readme.txt) for additional details.
